## Suggested execution notes

- **Phases 0-5 are the critical path to a first working warehouse.** Scope Lock → Extraction → Staging → Conformed Dimensions → Fact Tables → Data Quality is the shortest route from scaffold to a queryable, tested star schema. Land there before investing in orchestration (6), BI (7), scale-out (8), or polish (9).
- **Cache raw data locally and never re-fetch.** Every source is on a free tier with hard limits (SEC self-throttle, Alpha Vantage's ~25 req/day, Frankfurter/FRED/World Bank courtesy limits). Prefer bulk endpoints (Stooq over Alpha Vantage), land every response verbatim under `data/raw/<source>/`, and gate every fetch behind a freshness check so re-runs make zero network calls. The whole staging→marts pipeline should rebuild from landed raw with no live API access.
- **Prove the small subset correct before Phase 8 scale-out.** The 8-company / 4-country universe is deliberately small so its XBRL parsing, currency normalization, mixed-cadence reconciliation, and referential integrity can be verified by hand. Do not expand to the full ~40-name universe until the subset is green end-to-end (facts, dims, dbt tests, and dashboards); scaling a correct pipeline surfaces coverage gaps, whereas scaling an unproven one hides them.
